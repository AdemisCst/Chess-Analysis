# Chess-Analysis

Aplicativo local, em HTML/CSS/JavaScript puro, para importar partidas PGN,
analisar com Stockfish, acompanhar desempenho e gerar relatórios em PDF.

- Guia completo: [`LEIA-ME.md`](LEIA-ME.md)
- Auditoria e decisões: [`docs/AUDITORIA-INICIAL.md`](docs/AUDITORIA-INICIAL.md)
- Arquitetura: [`docs/ARQUITETURA-INTEGRACAO.md`](docs/ARQUITETURA-INTEGRACAO.md)
- Modelo de dados: [`docs/MODELO-DE-DADOS.md`](docs/MODELO-DE-DADOS.md)
- Diretrizes de UI: [`docs/UI-DIRETRIZES.md`](docs/UI-DIRETRIZES.md)
- Testes da Fase 1: [`docs/TESTES-FASE-1.md`](docs/TESTES-FASE-1.md)

Para abrir no PC, execute `iniciar.bat`. A análise com Stockfish exige o servidor
local; a biblioteca e os backups funcionam mesmo sem ele.
